# Project Management · Gantt Chart

A pure frontend, single-file HTML Gantt chart tool for project management. No installation or backend required — just open in a browser.

![Preview](preview.png)

## Features

- **Language Switch** — Toggle UI between Chinese and English (bilingual comments)
- **WBS Breakdown** — Organize tasks hierarchically
- **Gantt Chart Visualization** — Intuitive timeline and dependency view
- **Today Marker** — Auto-highlights the current date
- **Priority Levels** — Low / Medium / High / Critical
- **Predecessor Tasks** — Dependency linking between tasks
- **Milestones** — Zero-duration milestone markers
- **Progress Tracking** — Percentage progress bars
- **Data Persistence** — Auto-saves to browser local storage
- **Import / Export** — JSON format export and restore

## Usage

1. Open `index.html` in a browser
2. Click "+ Add Task" to create a new task
3. Drag task bars on the Gantt chart to adjust timing
4. Edit attributes in the table (name, duration, priority, etc.)
5. Data is automatically saved in the browser
